# Prompt Studio

A free, lightweight prompt-writing helper for creators and small businesses.

## What it does

- Helps write structured prompts for social posts, videos, branding, marketing, product descriptions, and emails.
- Lets you choose the audience, tone, and extra requirements.
- Generates a reusable prompt and lets you copy it.
- Works locally in a browser with no accounts or API keys.

**Important:** This is a prompt *builder*, not an AI model. It does not call an AI service or automatically generate the final marketing content.

## Run locally

1. Download the project files into one folder.
2. Open `index.html` in a browser.
3. Fill out the form, click **Generate prompt**, and copy the result.

## Tech

HTML, CSS, and vanilla JavaScript. No dependencies or build step.
